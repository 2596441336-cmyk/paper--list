# 纸上清单

一个放在 iPhone 主屏幕上的小应用：DDL 倒计时、日程、烦恼粉碎机，还有一只叫 **Bertholdt** 的伯恩山。

**在线使用：** https://2596441336-cmyk.github.io/paper--list/

## 怎么装到手机上

1. 用 iPhone 的 **Safari** 打开上面的网址
2. 点底部的「分享」按钮 → **添加到主屏幕**
3. 之后从桌面图标打开，就像普通 App 一样

每个人的数据只存在自己的手机里，互相看不到。把网址发给朋友，各自添加就行。

## 功能

- **要事**：记下有截止日期的事，每张卡片像一张票根，显示还剩几天；越临近颜色越醒目。完成后可以选择一种方式「送走」它。
- **日程**：按日期查看安排，支持每天 / 每周 / 每月 / 每年重复。
- **加入日历提醒**：一键把 DDL 写进 iPhone 自带的日历。默认在截止前 7 天、3 天、1 天和当天的 **11:00** 提醒（时间和频率可在设置里改）。提醒由系统日历发出，不打开应用也会准时弹出。
- **烦恼粉碎**：写下烦恼，然后撕碎、揉成团扔进垃圾桶、烧掉，或者折成纸飞机飞走。写的字不会被保存。
- **天气主题**：允许定位后，页面会跟着当地天气变：晴、多云、雨（含雷雨）、雾、雪，天黑自动切到夜间。也可以手动固定一种。
- **Bertholdt**：有自己的小窝、饭碗和水碗。可以喂饭（十几种食物，可以自己加）、加水、摸摸、扔球。它会饿、会开心也会失落，下雨天躲进小窝，下雪天在外面打滚。亲密度越高，它会从幼犬长成少年、再长成成年。不会生病，也不会离开。

## 隐私

- 所有记录保存在你手机浏览器的本地存储里，不上传到任何服务器。
- 定位只用来向 [Open-Meteo](https://open-meteo.com/) 查询天气，并向 BigDataCloud 查询城市名，不会被保存。
- 换手机前，在「设置 → 导出备份」保存一份数据文件。

## 技术说明

纯静态网页（HTML + CSS + 原生 JavaScript），无需构建，直接用 GitHub Pages 托管。

```
index.html            页面结构
css/style.css         样式与天气主题
js/store.js           本地数据与日期工具
js/weather.js         定位、天气查询、动态天空
js/ics.js             生成 iPhone 日历文件（.ics）
js/destroy.js         四种消除动画
js/dog.js             Bertholdt 的插画、状态与互动
js/sound.js           现场合成的音效
js/app.js             各页面逻辑
sw.js                 离线缓存
```
